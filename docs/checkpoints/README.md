# Daily checkpoints (activities 1–10)

What Bhaktivedanta Gurukula & International School asked the attendance app to
mark every weekday. Taken only from the school's own documents:

- SRS v1.2, 19 July 2026 — `docs/reference/attendance-requirements.md` §6 (the
  "initial weekday configuration") and rules S6, C1, C2
- The school's prototype, which the SRS says is part of the specification —
  `docs/reference/original-web-prototype.jsx`
- The school's 2025–26 register (415 students)

Times are the school's "indicative windows". Checkpoints, windows and groups are
configurable by the administrator without a developer.

## Rules that apply to every checkpoint

- Day scholars are left out of residential-only checkpoints automatically (S6).
- Everyone starts as Present; the marker only changes the exceptions (S1).
- Saturday morning and Sunday follow separate schedules "as in the current
  report book" (C1). Those timetables have not been given yet.
